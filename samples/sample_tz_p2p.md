# Техническое задание: сервис P2P-переводов по номеру телефона

## 1. Общие сведения
1.1 Наименование: мобильный сервис P2P-переводов «Перевод по номеру» для клиентов банка.
1.2 Заказчик: Департамент цифровых продуктов банка. Исполнитель: внутренняя команда разработки.
1.3 Сервис позволяет клиентам переводить деньги друг другу по номеру мобильного телефона в мобильном приложении банка.

## 2. Цели проекта
2.1 Увеличить количество активных пользователей мобильного приложения.
2.2 Сократить долю переводов, совершаемых через отделения.
2.3 Пользователь должен быть доволен скоростью и простотой переводов.

## 3. Функциональные требования
3.1 Клиент выбирает получателя из контактов телефона или вводит номер вручную.
3.2 Перевод подтверждается одноразовым SMS-кодом (OTP). Код подтверждения приходит быстро — не позднее 30 секунд. Код подтверждения действует 60 секунд.
3.3 Максимальная сумма одного перевода — 200 000 ₸. Суточный лимит переводов — 500 000 ₸.
3.4 После успешного перевода клиент получает push-уведомление и чек в формате PDF.
3.5 Система должна по возможности поддерживать переводы на карты других банков.
3.6 Переводы между клиентами банка выполняются без комиссии (комиссия 0%).
3.7 В случае ошибки система показывает пользователю сообщение об ошибке.
3.8 Система интегрируется с процессинговым центром и SMS-шлюзом.

## 4. Нефункциональные требования
4.1 Приложение должно работать быстро.
4.2 Система должна быть надёжной.
4.3 Интерфейс должен быть удобным и интуитивно понятным.
4.4 Сервис должен быть доступен всегда.
4.5 Система должна выдерживать большое количество пользователей.

## 5. Ограничения и лимиты
5.1 Сумма одной операции не может превышать 300 000 ₸. Срок действия OTP-кода — 5 минут.
5.2 Лимит переводов в сутки составляет 1 000 000 тенге.

## 6. Поддержка пользователей
6.1 Клиент может обратиться в поддержку через чат в приложении.
6.2 Оператор поддержки отвечает в кратчайшие сроки.
6.3 Оператор может отменить ошибочный перевод.

## 7. Тарифы
7.1 Комиссия за перевод — 0,5% от суммы, минимум 100 ₸.

## 8. Сроки
8.1 Промышленный запуск — 01.02.2027.
8.2 Пилот проводится с 01.03.2027 по 31.03.2027, промышленный запуск — 01.04.2027.
